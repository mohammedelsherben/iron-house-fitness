# AI video prompts for IRON HOUSE FITNESS

The website shows an AI-generated video automatically for an exercise when a file named after the exercise exists in `assets/exercises/`. No code changes are needed.

## How to use
1. Open any AI video generator (for example Sora, Veo, Runway, Kling, Luma or Pika).
2. Paste the **character description** below, then the **exercise line** for the file you want. Generate a 6–10 second clip.
3. Save it as MP4 with the exact file name shown (for example `assets/exercises/squat.mp4`). Create the `assets/exercises` folder next to `index.html` if it does not exist.
4. Open the exercise in the website: a tab **Watch the AI video** appears next to **Coach Karim explains**.

Tips: use the same character description every time so Coach Karim looks the same in all videos; ask for a steady camera, side or three-quarter view, and the full body in frame; 16:9 or 4:3 works best. AI videos can show wrong technique, so watch each one before publishing, and label them as AI-generated.

## Character description (use in every prompt)
> A fictional personal trainer named Coach Karim: a muscular man in his thirties with short dark hair and a short trimmed beard, wearing a lime-green fitted tank top, black shorts and white training shoes, in a modern dark gym with dumbbell racks and soft lighting.
